# Visuels produits

PNG 1600 × 1600 générés par `render.mjs` (Chromium headless via Playwright), puis téléversés
sur Shopify et rattachés aux 4 produits.

Ce sont des **illustrations**, pas des photographies. Deux raisons : les visuels du fournisseur
posent un problème de droits et de différenciation, et un échantillon n'a pas encore été
commandé. Remplace-les par de vraies photos dès réception — c'est ce qui convertit.

Pour régénérer après modification :

```
node render.mjs
```

Les couleurs suivent la charte de `site/vitrine.html` (papier blanc, vert pin, miel).
